# Hatchery Material Consumption Menu

The Hatchery page will load its existing `hatchery.css` stylesheet so the menu uses the available card-menu styles. Each Hatchery batch card will include a three-dot `details` menu in its header. The menu contains a Material Consumption Note action that opens the `fdcon` TStruct with `tobatch` set to the selected card’s batch ID, matching Parent and Grandparent.

The existing Chick Pull Out button and card content remain unchanged.
