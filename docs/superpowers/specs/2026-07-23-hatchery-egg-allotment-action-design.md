# Hatchery Egg Allotment Action

The Hatchery page will load its existing `hatchery.js` implementation instead of the removed `setter.js` file. In the list action group, Egg Grading will use an `eggGrading` action mapped to the `eggal` TStruct. A new `Add Egg Allotment` button will appear immediately after it and use the `eggAllotment` action mapped to `egall`.

The existing Egg Grading and Candle Test buttons retain their current behavior.
